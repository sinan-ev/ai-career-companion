# API Reference

The Backend is powered by **FastAPI** and orchestrates two AI-heavy modules. All responses are strictly typed using Pydantic models.

## Endpoints

### 1. Process Dataset
`POST /api/process`

Primary endpoint for data analysis. It accepts a file and returns a unified object containing intelligence from both Module 1 and Module 2.

**Request Body (Multipart Form):**
- `file`: .csv or .xlsx file.

**Response Body (UnifiedResponse):**
```json
{
  "module1": {
    "dataset_info": { "rows": 891, "domain": "Hospital", ... },
    "data_schema": { "numeric": ["Age", "Fare"], ... },
    "column_meanings": { "Age": "Age of the patient", ... },
    "ai_summary": "Narrative summary text...",
    "suggested_analyses": ["Trend of X vs Y", ...]
  },
  "module2": {
    "eda_report": { "quality_score": 85, "warnings": [...] },
    "dataset_outputs": {
      "target_column": "Survived",
      "ml_shape": [891, 14],
      "dataset_files": { "ml": "/downloads/result_ml.csv" }
    },
    "pipeline_steps": [
      { "step": "encoding", "status": "success", "details": "Encoded 3 columns" }
    ]
  }
}
```

### 2. Health Check
`GET /health`

Used to verify the status of the service and connected models.

## Core Data Models

### AnalysisResponse (Module 1)
- `dataset_info`: Structural metadata (sampled status, row/col counts).
- `data_schema`: Categorical/Numeric/Datetime classification.
- `column_meanings`: Human-readable explanations generated by AI.
- `data_quality`: Basic missing value and duplicate stats.

### Module2Response (Module 2)
- `eda_report`: Deep statistical profiling (Outliers, Skewness, Correlations).
- `dataset_outputs`: Info on the two exported datasets (Analytics vs ML).
- `pipeline_steps`: The "Memory" log of the AI-planned cleaning actions.
- `artifact_paths`: Paths to the versioned `.pkl` files for production deployment.

## Internal Directory Logic
- `/exports`: Contains the actual cleaned CSV files served via `/downloads/`.
- `/artifacts`: Contains `.pkl` files (Encoders/Scalers) organized by `{domain}_{timestamp}`.
